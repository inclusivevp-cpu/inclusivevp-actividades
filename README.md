# Inclusive · Actividades

Página de actividades (gratis y de pago) para viajeros de Inclusive, publicada con GitHub Pages.

- Datos: pestaña **Web** de la hoja ACTIVIDADES (publicada como CSV). Editar la hoja actualiza la página en unos minutos.
- Pedidos: el botón "Enviar mi selección" guarda en la pestaña **Pedidos** mediante `apps-script/Code.gs`.
- Ajustes en `index.html`: `CSV_URL` y `ORDER_URL`.
